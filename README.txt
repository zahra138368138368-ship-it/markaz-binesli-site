نسخه نهایی — آماده انتشار

مرکز فرهنگی با تأکید بر مشارکت بین‌نسلی | قم

این نسخه برای انتشار استاتیک آماده شده و وابستگی اصلی آن به سرویس خارجی ندارد.

نکات:
- فایل index.html صفحه اصلی است.
- مسیرهای داخلی با Hash Routing کار می‌کنند.
- منوی موبایل، گالری/لایت‌باکس، پرسش‌های معماری و پنجره ثبت‌نام آزمایشی فعال هستند.
- ثبت‌نام فعلی نمایشی است و ظرفیت‌ها در localStorage مرورگر ذخیره می‌شوند؛ سامانه ثبت‌نام آنلاین/پایگاه‌داده نیست.
- فونت‌های فارسی داخل پوشه fonts قرار دارند.
- برای انتشار، کل محتویات این پوشه را روی Netlify یا هر سرویس میزبانی استاتیک قرار دهید.
- پس از انتشار، آدرس HTTPS نهایی را می‌توان برای ساخت QR Code استفاده کرد.
